* [[https://owncloud.gwdg.de/index.php/s/gBUs2jg5WA8g3lO][Classifying the Genomes of /E. coli/ Strains]]
This analysis is part of a forthcoming manuscript entitled
/Classifying E. coli genomes into phylotaxa/.

** Authors
Beatriz Vieira Mourato, Sara-Lena Welk, Fabian Klötzl, and Bernhard
Haubold

** Dependencies
This tutorial has six main dependencies:
- [[https://github.com/evolbioinf/neighbors][Neighbors]] for finding target and neighbor genomes
- [[https://www.ncbi.nlm.nih.gov/datasets/][datasets]] and [[https://ftp.ncbi.nlm.nih.gov/pub/datasets/command-line/v2/linux-amd64/dataformat][dataformat]] for downloading and analyzing genomes
- [[https://github.com/evolbioinf/fur][Fur]] for finding unique genome regions
- [[https://github.com/evolbioinf/prim/][Prim]] for designing PCR primers
- [[https://github.com/evolbioinf/biobox][Biobox]] for general sequence manipulation
- the Unix tools =curl=, =bzip2=, and =zip= for downloading and
  decompressing files
If you are on a Debian system like WSL/Ubuntu, you can install these
dependencies into =~/bin/= by executing from inside the =o111h8= repo
#+begin_src sh
  bash scripts/setup.sh
#+end_src
Once that's done, make sure =~/bin/= is in your path by running
#+begin_src sh
source ~/.profile
#+end_src
We have tested this setup on our "minimal box" Docker container, [[https://hub.docker.com/r/haubold/mix][mix]].

** Download the Neighbors database
Execute
#+begin_src sh
  make neidb
#+end_src
to download the Neighbors database, =neidb=, into the =data=
directory. Since =neidb= is 1.3 GB large, this takes a couple of
minutes. The result is a fifth data file inside =data=, =neidb=. This
is an Sqlite database calculated from the [[https://ftp.ncbi.nlm.nih.gov/genomes/ASSEMBLY_REPORTS/assembly_summary_genbank.txt][Genbank assemblies]], [[https://ftp.ncbi.nlm.nih.gov/genomes/ASSEMBLY_REPORTS/assembly_summary_refseq.txt][Refseq
assemblies]], and the [[https://ftp.ncbi.nlm.nih.gov/pub/taxonomy/taxdump.tar.gz][taxonomy database]] downloaded from the NCBI on 17th
June 2026. The original data files are archived [[https://neighbors.evolbio.mpg.de/databases/2026_Jun_17.tgz][here]].

** Data Files
Apart from the binary file =neidb=, the =data= directory contains five
data files in text format:

- =acc.txt=, the accessions of the 7361 complete /E. coli/ genomes
  used in the phylogeny reconstruction
- =eco.json=, the genome summaries of the 7884 /E. coli/ genomes
  assembled to level "complete"
- =eco.nwk=, the tree of the 7361 complete /E. coli/ genomes that
  passed the quality filter applied to the 7884 complete genomes
- =mlst.txt=, the sequence types of the 7361 complete /E. coli/
  genomes used for calculating =eco.nwk= retrieved using the program
  [[https://github.com/tseemann/mlst][mlst]]
- =sero.txt=, the serotypes of the 7361 complete /E. coli/ genomes
  used for calculating =eco.nwk= looked up with [[https://github.com/phac-nml/ecoli_serotyping][ectyper]]


** Tutorial
Make the tutorial and change into it.
#+begin_src sh
  make tutorial
#+end_src
This now contains the scripts and data files for following the
tutorial described in the [[https://owncloud.gwdg.de/index.php/s/jzF2dkp7L5xjqP1][doc]]. We can also run all scripts to test
them.
#+begin_src bash
  cd tutorial
  bash testTut.sh
#+end_src
